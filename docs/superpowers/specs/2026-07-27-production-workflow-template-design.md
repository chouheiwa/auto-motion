# 完整视频制作模板设计

## 目标

在不改变现有轻量流程的前提下，新增一份可重复使用的完整制作任务模板。它适用于把文章、口播稿或参考字幕制作成带配音、字幕、MG 动画、首帧封面、背景音乐和音效的竖屏成片。

模板是可复用的，执行结果不是可复用的。每篇内容都必须在新的干净项目目录或独立 Git worktree 中运行，并拥有自己的输入快照、生成目录、日志、素材证据、审批记录和最终成片。

## 文件边界

- 保留 `PROMPT.md`：继续承担“已有定稿 SRT → 静音 MG 镜头 → `final.mp4`”的基础流程。
- 新增 `PROMPT-PRODUCTION.md`：承担完整生产流程。
- 更新 `README.md`：说明两个模板的适用场景、输入、输出和运行方式。
- 更新 `README.en.md`：同步入口和运行边界，避免双语文档信息冲突。
- 不修改 `exampleFolder/run-claude-ai.sh` 的执行契约。
- 不把本次作品的文案、音色、音乐、音效、镜头设计、时长或审批结果写成下一次任务的默认事实。

## 完整流程

### 1. 建立一次性项目

执行前确认当前目录是为本篇内容新建的干净目录或独立 worktree。生成唯一的项目标识，记录当前 Git 提交和输入文件哈希。已有同名生产目录时停止，不覆盖旧结果。

### 2. 输入盘点与制作规格

接受文章、口播稿、参考 SRT、已有配音和视觉参考中的一种或多种输入。先生成输入清单，再确定平台、画幅、帧率、目标时长、配音策略、首帧文案和声音方向。

参考 SRT 只能提供内容与大致节奏；未录制配音时，不把它当作不可更改的最终时间轴。

### 3. 口播稿与开场

整理适合口语表达的终稿，修复不自然断句，并在需要时补充约 12–15 秒的开场，明确视频要解决的问题。专有名词、英文产品名和强语义短语不得被错误拆开。

### 4. TTS 与真实时间轴

从 `.env` 读取 MiniMax 凭据，不在文件、日志或命令输出中暴露密钥。按语义段落生成语音，保存请求参数、非敏感响应、音频和时间戳。试听或检查断句后再冻结音色。

最终 SRT 以实际语音时间戳为基础生成，并根据画面信息密度加入停顿、收尾和转场空间。字幕覆盖整个节目时间线，毫秒精度不丢失。

### 5. 分镜与 Claude 渲染

按语义、因果关系和单一视觉概念做粗粒度分镜。镜头首尾相接并覆盖完整时间线。每个镜头从 `exampleFolder` 建立独立目录，复制完整字幕，并填写单镜头运行脚本。

Claude Code 负责每个镜头内部的创意、代码和 MP4 渲染；调度方只提供与文案相符的创意方向，不代写具体动画方案。同一时间只运行一个 Claude 调用，并保留三类日志。

### 6. 首帧封面

竖屏发布默认需要可读的第 0 帧。封面文案必须预先确定，并在第 0 帧完整可见；安全区、行数、对比度和稳定帧数应成为可验证合同。封面转入正文时不能造成黑帧或不可读的中间状态。

### 7. 视频规范化与拼接

逐镜头检查分辨率、帧率、像素格式、色彩信息、编码、时长和音轨。规格不一致时先规范化，再按顺序拼接为静音母版。单镜头也必须生成统一命名的母版文件。

### 8. 音乐、音效与混音

只使用来源与授权可追溯的音乐和音效，保存原始链接、作者、授权说明和 SHA-256。背景音乐服务于叙述，不抢人声；音效只放在信息节点、转场或关键反馈处。

混音应包含人声优先、音乐侧链或自动压低、首尾淡化、峰值控制、响度检查和完整解码。不得为了“热闹”给每个动作都加音效。

### 9. 验收与原子交付

验收至少覆盖：

- 字幕总跨度、镜头时长和最终帧数一致。
- 首帧封面在第 0 帧可读，没有黑帧。
- 所有镜头和最终 MP4 可完整解码。
- 视频规格统一，音频采样率、声道和节目终点正确。
- 人声清晰，BGM 与 SFX 不遮挡关键词。
- 日志、素材账本、检查表和审批文件齐全。

候选成片通过验收后再原子替换 `final.mp4`；已有成片必须先保留备份。机器检查不能代替最终的耳机和手机外放人工试听。

## 失败处理

- TTS 失败：保留请求与错误信息，检查凭据、额度、音色和接口响应后重试，不伪造时间戳。
- Claude 长时间无阶段消息：同时检查流日志、错误日志、文件更新时间和渲染进程，不能只凭静默判失败。
- 单镜头失败：记录镜头编号、失败阶段和关键日志，只重试该镜头。
- 规格不一致：规范化副本，不覆盖 Claude 的原始交付。
- 最终验收失败：保留候选与报告，不替换当前 `final.mp4`。

## 成功标准

下一篇内容可以只替换输入文件和本次项目配置，直接使用完整模板执行；操作者无需参考上一条视频的对话历史，也不会误用上一条视频的素材或审批结果。基础模板原有行为和 E2E 契约保持不变。
